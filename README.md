# Untitled

## Description

A 2D game inspired by the classic game _Space Impact_. This project is being developed as part of **SMAUG** _(Sistema Maximizado de Avaliação Unificada)_, an assessment program for the second semester of the **Jogos Digitais** course at **FATEC Carapicuíba**.

## About SMAUG

**SMAUG** _(Sistema Maximizado de Avaliação Unificada)_ is an assessment program used in the **Jogos Digitais** course at **FATEC Carapicuíba**. As part of the program, students develop a game each semester, which contributes to their final grades across the courses involved.

The name is also a reference to Smaug, the dragon from _The Hobbit_.

- Pygame
